# Rabbit 网盘 · 接口文档

> 基础地址：`/api/v1`　|　在线调试：部署后打开 `http://<host>/doc.html`（Knife4j）
>
> 请求格式：`application/json`（上传 `multipart/form-data`）；时间格式 `yyyy-MM-dd HH:mm:ss`；UTF-8

## 通用约定

**统一响应体**

```json
{ "code": 200, "message": "success", "data": { } }
```

| code      | 含义                                |
| --------- | --------------------------------- |
| 200       | 成功                                |
| 400       | 参数错误                              |
| 401       | 未登录 / 令牌失效（前端自动用 refreshToken 续期） |
| 403       | 无权限                               |
| 404       | 资源不存在                             |
| 429       | 触发限流                              |
| 500       | 服务异常                              |
| 1001-1016 | 业务错误码（见文末表）                       |

**鉴权**：需登录接口请求头携带 `Authorization: Bearer {accessToken}`；媒体标签（img/video）无法带请求头时支持 `?token={accessToken}` 查询参数。401 时前端自动调 `/user/refresh` 轮换并重放原请求。

**分页响应**（`data` 结构）：

```json
{ "records": [ ... ], "total": 128, "size": 50, "current": 1, "pages": 3 }
```

## 1. 用户认证与账号

### 1.1 注册 `POST /user/register`　公开

| 字段         | 类型     | 必填 | 说明                                        |
| ---------- | ------ | -- | ----------------------------------------- |
| username   | string | 是  | 4-32 位字母数字\_-                             |
| password   | string | 是  | 6-32 位                                    |
| nickname   | string | 否  | ≤32 位，默认同用户名                              |
| inviteCode | string | 是  | **注册口令码**（12 位，管理员后台生成，一码一用；无效/已用返回 1017） |

```bash
curl -X POST http://host/api/v1/user/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"tom","password":"123456","nickname":"汤姆","inviteCode":"8xQ2kP9zR4aL"}'
```

### 1.2 登录 `POST /user/login`　公开（限流 10 次/分钟/IP；失败 5 次锁 15 分钟）

请求：`{"username":"admin","password":"Admin@123456"}`

```json
// data
{
  "accessToken": "eyJhbGciOi...",
  "refreshToken": "eyJhbGciOi...",
  "accessExpiresIn": 7200,
  "user": { "id": 1, "username": "admin", "nickname": "管理员", "avatar": null,
            "role": "ADMIN", "status": 1, "storageUsed": 0, "storageTotal": 214748364800,
            "fileCount": 0, "createTime": "2026-10-24 12:00:00" }
}
```

### 1.3 刷新令牌 `POST /user/refresh`　公开

请求：`{"refreshToken":"eyJhbGciOi..."}` → 响应同 1.2（旧 refreshToken 轮换失效）。

### 1.4 登出 `POST /user/logout`　需登录

请求体（可选）：`{"refreshToken":"..."}`。使当前令牌立即失效。

### 1.5 修改密码 `PUT /user/password`　需登录

请求：`{"oldPassword":"...","newPassword":"..."}` → 成功后**所有设备强制下线**。

### 1.6 当前用户信息 `GET /user/info`　需登录

`data` 同登录返回中的 `user`（含存储用量/配额/文件数）。

### 1.7 上传头像 `PUT /user/avatar`　需登录（multipart）

| 参数   | 说明        |
| ---- | --------- |
| file | 图片文件，≤2MB |

→ `data: {"avatarUrl": "/api/v1/user/avatar/1?v=..."}`  
头像访问（公开）：`GET /user/avatar/{userId}`。

### 1.8 修改昵称 `PUT /user/nickname`　需登录

请求：`{"nickname":"新昵称"}`

### 1.9 个人操作日志 `GET /user/logs?pageNum=1&pageSize=10`　需登录

`records[]`：`{id,userId,action,detail,ip,createTime}`，action ∈ LOGIN/LOGOUT/UPLOAD/DELETE/SHARE/DOWNLOAD/RESTORE/…

## 2. 文件与目录管理　（均需登录）

### 2.1 目录列表 `GET /file/list`

| 参数                                   | 说明                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------- |
| parentId                             | 父目录，根目录传 0                                                             |
| pageNum / pageSize                   | 默认 1 / 50                                                              |
| sortField                            | fileName / size / updateTime / createTime（默认 updateTime）               |
| sortOrder                            | asc / desc（文件夹始终置顶）                                                    |
| keyword / type / startTime / endTime | 传任一条件即变为**全局搜索**（递归），type ∈ image/video/audio/doc/pdf/txt/md/zip/other |

`records[]`（FileVO）：

```json
{ "id": 42, "parentId": 0, "fileName": "资料.zip", "isDir": false, "size": 10485760,
  "fileType": "zip", "ext": "zip", "md5": "d41d8cd9...", "createTime": "...", "updateTime": "..." }
```

### 2.2 新建文件夹 `POST /file/folder`　`{"parentId":0,"fileName":"项目资料"}` → FileVO

### 2.3 重命名 `PUT /file/rename`　`{"fileId":42,"fileName":"新名称"}`（同级重名报 1003）

### 2.4 移动 `PUT /file/move`　`{"fileIds":[1,2],"targetParentId":5}`

校验：目标为本人文件夹；不可移入自身/子目录（防环）。

### 2.5 复制 `POST /file/copy`　请求同 2.4 → `data: {"copied": 2}`（文件夹递归复制）

### 2.6 删除（移入回收站）`DELETE /file/delete?fileIds=1,2,3`　→ `{"deleted": 3}`

### 2.7 批量操作 `POST /file/batch`

```json
{ "fileIds": [1,2,3], "operation": "delete|move|copy", "targetParentId": 5 }
```

### 2.8 文件搜索 `GET /file/search?keyword=报&type=pdf&pageNum=1&pageSize=50`　参数同 2.1（全局搜索）

### 2.9 文件详情 `GET /file/{id}`　→ FileVO（完整元数据含 MD5）

## 3. 上传　（均需登录）

### 3.1 秒传校验 `POST /upload/check`

```json
{ "fileName": "movie.mp4", "fileSize": 734003200, "md5": "<前端 spark-md5 计算>", "parentDirId": 0 }
```

```json
// 命中（空间校验通过后直接建行）
{ "finished": true, "fileId": 100 }
// 未命中
{ "finished": false }
```

### 3.2 初始化分片 `POST /upload/init`　请求同 3.1

```json
{ "uploadId": "b1e2...9f", "chunkSize": 5242880, "uploadedChunks": [] }
```

### 3.3 断点续传 `POST /upload/resume?uploadId={原uploadId}`　请求体同 3.1 → 返回已传分片序号列表

### 3.4 上传分片 `POST /upload/chunk`（multipart/form-data）

| 参数         | 说明      |
| ---------- | ------- |
| uploadId   | init 返回 |
| chunkIndex | 从 0 开始  |
| file       | 该分片二进制  |

### 3.5 合并分片 `POST /upload/merge`

```json
{ "uploadId": "b1e2...9f", "fileName": "movie.mp4", "fileSize": 734003200,
  "md5": "...", "parentDirId": 0 }
```

→ `data: {"fileId": 100}`。校验分片完整性后 MinIO 服务端拼接，自动清理临时分片。

### 3.6 取消上传 `DELETE /upload/{uploadId}`　清理已传分片与任务状态

### 3.7 单文件直传 `POST /upload/single`（multipart，`parentDirId` 放 query）　→ `{"fileId": 100}`

> 通用限制：单文件上限/允许扩展名由管理后台配置；`exe/bat/cmd/js/vbs/scr/com/msi/sh/ps1/dll` 系统级强制拦截；PE 魔数伪装同样拦截。

## 6. 分享与 12 位短链

### 6.1 生成分享 `POST /share/create`　需登录

| 字段          | 类型     | 说明                   |
| ----------- | ------ | -------------------- |
| fileId      | long   | 分享的文件/文件夹 ID（须本人所有）  |
| expireDays  | int    | 0=永久，1/7/30…=天数      |
| password    | string | 可空；4-6 位字母数字（MD5 存储） |
| maxView     | int    | 最大访问次数，-1 不限         |
| canDownload | bool   | false=仅预览            |

```json
// data
{ "shareId": 189234567890123456, "shortCode": "8xQ2kP9zR4aL",
  "shortUrl": "https://pan.example.com/s/8xQ2kP9zR4aL",
  "fileName": "资料.zip", "fileSize": 10485760, "isDir": false,
  "hasPassword": true, "maxView": 100, "viewCount": 0, "canDownload": true,
  "expireTime": "2026-10-31 12:00:00", "status": 1, "createTime": "..." }
```

### 6.2 我的分享 `GET /share/list?pageNum=1&pageSize=10`　→ 分页 ShareVO

### 6.3 撤销分享 `DELETE /share/{id}`　立即失效（删记录 + 删 Redis 映射）

### 6.4 更新分享 `PUT /share/{id}`　短码不变

```json
{ "expireDays": 30, "password": "ab12cd", "maxView": 500, "canDownload": false }
```

> password 传 `""` 表示清除提取码；不传表示不修改。

### 6.5 短链跳转入口 `GET /s/{shortCode}`　公开（Nginx 反代 + 限流 10r/s）

校验通过 **302 重定向**到 `{FRONTEND_BASE_URL}/share/{shortCode}` 前端分享页；失效/过期由前端页展示对应状态。

### 6.6 分享基本信息 `GET /share/{shortCode}/info`　公开

```json
{ "shortCode": "8xQ2kP9zR4aL", "fileId": 42, "fileName": "资料.zip", "fileSize": 10485760,
  "isDir": false, "needPassword": true, "expireTime": "...", "canDownload": true,
  "ownerName": "管理员" }
```

> 每次成功访问 `viewCount +1`；错误码：1009 无效 / 1010 过期 / 1012 超访问上限。

### 6.7 校验提取码 `POST /share/{shortCode}/verify`　公开

请求：`{"password":"ab12cd"}` → `{"shareToken":"c9f3...e2"}`（2 小时有效）

### 6.8 分享文件列表 `GET /share/{shortCode}/list?shareToken=...&dirId=0`　公开（凭证保护）

文件夹分享浏览：dirId=0 为分享根；返回 `FileVO[]`。

### 6.9 分享文件下载 `GET /share/{shortCode}/download/{fileId}?shareToken=...`

`canDownload=false` 时返回 1015“该分享仅支持在线预览”；支持 Range。

### 6.10 分享文件预览 `GET /share/{shortCode}/preview/{fileId}?shareToken=...&thumb=1`

图片/音视频/PDF/TXT/MD 同 §5 行为。

## 9. 管理员后台　（均需 ADMIN 角色，越权返回 403）

| 接口     | 方法/路径                                                  | 说明                                                         |
| ------ | ------------------------------------------------------ | ---------------------------------------------------------- |
| 用户列表   | `GET /admin/user/list?pageNum&pageSize&keyword&status` | 分页，含各用户用量                                                  |
| 新增用户   | `POST /admin/user`                                     | `{"username","password","nickname","quotaGb"}`             |
| 修改配额   | `PUT /admin/user/quota`                                | `{"userId":2,"quotaGb":200}`                               |
| 禁用/启用  | `PUT /admin/user/status`                               | `{"userId":2,"status":0}` 禁用即强制下线                          |
| 删除用户   | `DELETE /admin/user/{id}`                              | 级联删除其全部文件/分享/日志（管理员不可删）                                    |
| 全局文件检索 | `GET /admin/file/search?keyword&pageNum&pageSize`      | 跨用户                                                        |
| 删除违规文件 | `DELETE /admin/file/{id}`                              | 物理删除并记录日志                                                  |
| 获取配置   | `GET /admin/config`                                    | maxFileMb / allowedExts / recycleKeepDays / defaultQuotaGb |
| 修改配置   | `PUT /admin/config`                                    | 字段可选，仅更新传入项                                                |
| 数据统计   | `GET /admin/statistics`                                | 用户数/文件数/存储用量（storageTotal = **系统总空间**）/今日操作/今日登录           |

### 9.1 注册口令码　（均需 ADMIN 角色）

| 接口    | 方法/路径                                            | 说明                                                |
| ----- | ------------------------------------------------ | ------------------------------------------------- |
| 批量生成  | `POST /admin/invite/generate`                    | `{"count": 5}`（1-50）→ `InviteCode[]`，算法与 12 位短链一致 |
| 口令码列表 | `GET /admin/invite/list?pageNum&pageSize&status` | status：1 可用 / 0 已使用或已作废                           |
| 作废    | `DELETE /admin/invite/{id}`                      | 仅可用状态可作废                                          |

`InviteCode` 结构：

```json
{ "id": 3, "codeId": 189234567890123456, "code": "8xQ2kP9zR4aL", "createUserId": 1,
  "usedBy": null, "usedTime": null, "status": 1, "expireTime": null,
  "createTime": "2026-10-24 12:00:00" }
```

> 注册时校验流程：码存在且可用 → 未过期 → 数据库原子占用（`status=1 → 0`，并发抢同一码只有一个成功）→ 注册成功；失败整体回滚并返回 1017。

## 10. 业务错误码总表

| code | 含义              | 典型场景                             |
| ---- | --------------- | -------------------------------- |
| 1001 | 登录失败次数过多，账号临时锁定 | 连续输错 5 次密码                       |
| 1002 | 用户名已存在          | 注册/后台建用户                         |
| 1003 | 同名文件或文件夹已存在     | 新建/重命名/恢复                        |
| 1004 | 文件不存在或已被删除      | 越权访问 / 已删除                       |
| 1005 | 存储空间不足          | 上传/秒传配额校验                        |
| 1006 | 该文件类型不允许上传      | 高危扩展名 / 不在允许列表                   |
| 1007 | 文件大小超出限制        | 超过 max_file_mb                   |
| 1008 | 上传任务不存在或已过期     | 分片任务超 24h / 分片不完整                |
| 1009 | 分享链接不存在或已失效     | 已撤销 / 短码错误                       |
| 1010 | 分享链接已过期         | 超过 expire_time                   |
| 1011 | 提取码错误           | verify 失败                        |
| 1012 | 分享访问次数已达上限      | view_count ≥ max_view            |
| 1013 | 账号或密码错误         | 登录失败                             |
| 1014 | 原密码错误           | 修改密码                             |
| 1015 | 不允许的操作          | 仅预览分享请求下载 / Office 预览 / 移入自身子目录等 |
| 1016 | 账号已被禁用          | 管理员禁用后登录                         |
| 1017 | 口令码无效或已被使用      | 注册时口令码校验失败                       |
| 1018 | 系统存储空间已满        | 全系统已用达到 total_storage_gb         |

## 11. 完整调用示例（登录 → 上传 → 分享）

```bash
BASE=http://localhost/api/v1

# 1) 登录
TOKEN=$(curl -s -X POST $BASE/user/login -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Admin@123456"}' | grep -o '"accessToken":"[^"]*' | cut -d'"' -f4)

# 2) 新建文件夹
curl -s -X POST $BASE/file/folder -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"parentId":0,"fileName":"测试目录"}'

# 3) 直传文件
curl -s -X POST "$BASE/upload/single?parentDirId=0" \
  -H "Authorization: Bearer $TOKEN" -F "file=@./hello.txt"

# 4) 创建 7 天分享（提取码 1234，可下载）
curl -s -X POST $BASE/share/create -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"fileId":1,"expireDays":7,"password":"1234","maxView":-1,"canDownload":true}'
# → shortUrl: http://localhost/s/Xk29fPq7Az1L

# 5) 访客侧：查信息 → 验码 → 下载
curl -s $BASE/share/Xk29fPq7Az1L/info
TOKEN2=$(curl -s -X POST $BASE/share/Xk29fPq7Az1L/verify -H 'Content-Type: application/json' \
  -d '{"password":"1234"}' | grep -o '"shareToken":"[^"]*' | cut -d'"' -f4)
curl -sOJ "$BASE/share/Xk29fPq7Az1L/download/1?shareToken=$TOKEN2"
```
