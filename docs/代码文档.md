## 3. 核心算法与机制

### 3.1 12 位加密短链（`ShortCodeGenerator` + `ShareService`）

```
shareId(雪花64位)
  → x = shareId ^ saltLong               # 盐值异或（盐值经 FNV 风格折叠成 64 位）
  → x = rotateLeft(x, 21)
  → x = x * 0x9E3779B97F4A7C15           # 黄金分割乘数，比特雪崩
  → x = rotateLeft(x, 37); x ^= x>>>29   # 再混淆
  → Base62 无符号编码（≤11 字符）→ 左填充 '0' 至 11 位
  → 追加 1 位随机 Base62 → 固定 12 位
```

- **不可枚举**：同一 shareId 恒定输出同一短码，但短码与自增 ID 无线性关系，3.2×10²¹ 组合空间。
- **唯一性兜底**：`short_code` 唯一索引；插入遇 `DuplicateKeyException` 自动换 shareId 重试（≤5 次）。
- **访问链路**：`GET /s/{code}` → `resolveByShortCode`：优先 Redis `share:code:{code}`，未命中回源 MySQL 并回填缓存（TTL 与分享有效期一致）→ 依次校验 状态/过期/访问上限 → 302 到 `{FRONTEND_BASE_URL}/share/{code}` 前端分享页。
- **提取码**：前端明文 → 后端 MD5 存库；`verify` 通过后签发 2 小时 `shareToken`（UUID，Redis `share:temp:{token}`），后续 `list/download/preview` 凭 token 访问，且校验"短码与 token 指向同一分享"与"文件在分享子树内"双重防越权。

### 3.2 分片上传 / 断点续传 / 秒传（`UploadService` + 前端 `stores/upload.js`）

```
前端 spark-md5 分片计算 MD5（8MB 步长）
  → POST /upload/check：MD5 全局命中 → 引用同一存储对象直接建行（秒传）
  → POST /upload/init：生成 uploadId，元数据存 Redis hash（TTL 24h），返回 chunkSize=5MB
  → POST /upload/chunk：分片存 MinIO tmp/chunk/{uploadId}/{index}，序号 sAdd 进 Redis Set
  → POST /upload/merge：完整性校验(已传数=总分片数)
      chunkCount==1 → copyObject
      否则          → composeObject 服务端拼接（除最后一片外每片 ≥5MB 的 S3 约束由 chunkSize 保证）
      → statSize 校验 → 建文件行（记录 md5）→ 清理临时分片与 Redis
  → 暂停/恢复：前端 pause 标志停止队列；resume 重新 init 获取 Redis 中已传分片集合，仅补传缺失分片
```

- 配额在 check/init/merge 三个环节都会校验；高危扩展名（exe/bat/js…）系统级强制拦截 + 可配置 allowed_exts + PE 魔数（MZ）伪装检测。
- 取消上传 `DELETE /upload/{uploadId}` 批量清理 tmp 对象。

### 3.3 JWT 双令牌（`AuthService` / `JwtAuthenticationFilter`）

| 令牌           | 时效 | 存储                                   | 用途                                  |
| ------------ | -- | ------------------------------------ | ----------------------------------- |
| accessToken  | 2h | Redis `login:token:{token}`→userId   | 业务请求 `Authorization: Bearer`        |
| refreshToken | 7d | Redis `refresh:token:{token}`→userId | 仅 `/user/refresh`，轮换制（旧 token 立即删除） |

- accessToken 同时登记进 `login:user:{userId}` 集合 → 修改密码 / 管理员禁用用户时按集合批量失效，实现**强制全端下线**。
- refresh 令牌**不能**访问业务接口（filter 按claims.type 判定拒绝）。
- 前端 axios：并发 401 合并为一次 refresh（promise 队列），成功后重放原请求。

### 3.4 安全要点

- **配额模型**：双重校验（`StorageService.checkQuota`）——① 用户已用 + 新增 ≤ 用户配额（新用户默认 5GB）；② 全系统已用 + 新增 ≤ `total_storage_gb`（默认 30GB）。管理员初始配额即系统总空间。
- **注册口令码**：管理员后台批量生成（与 12 位短链同款雪花+混淆+Base62 算法，不可枚举）；注册时同事务原子消费（`UPDATE ... WHERE status=1` 抢占式更新，并发一码一用），Redis 缓存加速校验、消费即删。
- **水平越权防护**：所有文件读写经 `FileService.getOwned(userId, fileId)` 强制所属权；分享子树校验 `inSubtree`；移动/复制做环检测（不能移入自身子目录）。
- **限流**：Redis 计数器按 IP，登录/注册 10 次/分钟，短链与提取码 60 次/分钟，Nginx 层再叠加 30r/s、10r/s。
- **登录保护**：失败 5 次锁 15 分钟（`login:fail:{username}`）。
- **密码**：BCrypt 存储；改密强制下线。
- **物理删除引用计数**：秒传/复制会让多个文件行共享一个 MinIO 对象，永久删除/管理端删除时 `COUNT(storage_path)` 为 0 才真正 remove。
- SQL 注入：MyBatis-Plus 参数化 + 排序字段白名单映射；XSS：Vue 模板默认转义，富文本仅 Markdown 渲染（v-html 仅限 md 内容）。

### 4.1 数据模型（Flyway `V1__init_schema.sql`）

- `sys_user`：username 唯一、BCrypt 密码、role、status、storage_total（字节）
- `file_info`：user_id + parent_id + status 联合索引；is_dir、size、file_type、ext、storage_path、md5、original_parent_id/delete_time（回收站）
- `file_share`：share_id（雪花）、short_code 唯一、password(MD5)、expire_time、max_view、view_count、can_download、status
- `sys_config`：max_file_mb / allowed_exts / recycle_keep_days / default_quota_gb(默认 5) / **total_storage_gb(默认 30，系统总空间)**
- `invite_code`：注册口令码。code_id（雪花）、code（12 位 Base62，与短链同款混淆算法）、status（1 可用/0 已用或作废）、used_by/used_time（一码一用留痕）、expire_time
- `op_log`：action/detail/ip/create_time，(user_id,create_time) 与 (action,create_time) 索引

### 4.2 Redis Key 一览

| Key                        | 结构                     | 说明          |
| -------------------------- | ---------------------- | ----------- |
| `login:token:{access}`     | string→userId TTL2h    | 登录态         |
| `refresh:token:{refresh}`  | string→userId TTL7d    | 刷新令牌        |
| `login:user:{userId}`      | Set(全部令牌)              | 强制下线用       |
| `login:fail:{username}`    | counter TTL15min       | 登录失败锁定      |
| `invite:code:{code}`       | string→codeId          | 口令码缓存（消费即删） |
| `share:code:{shortCode}`   | string→shareId TTL=有效期 | 短链映射        |
| `share:temp:{tempToken}`   | string→shareId TTL2h   | 公开访问凭证      |
| `upload:task:{uploadId}`   | hash 元数据 TTL24h        | 分片任务        |
| `upload:chunks:{uploadId}` | Set(分片序号) TTL24h       | 已传分片        |
| `zip:task:{taskId}`        | JSON 状态                | 打包任务        |
| `rate:{pattern}:{ip}`      | counter TTL60s         | 限流          |

## 5. 前端关键实现

- **液态玻璃主题**（`styles/index.scss`）：CSS 变量定义三级玻璃（blur 24/16/12px + saturate 递减），`.glass-1/2/3` 工具类统一附加 `translateZ(0)` 硬件加速与极柔外阴影；Element Plus 按钮/输入框/弹窗/Toast/下拉全部深度覆盖；`html.dark` 切换暗色变量并配合 EP dark css-vars，颜色过渡 0.4s 无闪烁。文件列表行**不使用** backdrop-filter（性能），模糊只保留在大区块。
- **LiquidBackground**：canvas 4 个径向渐变色块按 `sin/cos(t)` 慢速漂移（20-30s 周期），亮色 `lighter` 叠加、暗色 `source-over`；`hardwareConcurrency≤4`、`deviceMemory≤4` 或 `prefers-reduced-motion` 时静态渲染一帧；`visibilitychange` 暂停。
- **上传引擎**（`stores/upload.js`）：Pinia 单例管理队列；MD5 增量计算映射进度 0-40%，分片上传映射 40-99%；3 路并发；速度/ETA 由 3 秒滑动采样计算；暂停置标志位，续传重新 init 只补缺失分片；取消调用服务端清理接口。
- **公开分享页**：`状态机 loading→invalid|password|ready`；文件夹面包屑浏览；预览复用 `PreviewModal`（分享模式 URL 走 `/share/{code}/preview/{id}?shareToken=`）。
- **构建产物**：路由懒加载 + manualChunks（vue / element-plus 独立分包），文件名带 hash，配合 Nginx `immutable` 强缓存。

## 7. 已知限制（与需求文档取舍说明）

按需求文档"优先第一阶段 + 12 位短链 + 液态玻璃 UI"的取舍原则：

1. **Office 文档（doc/xlsx/ppt）暂不支持在线预览**：提示下载查看；接入 OnlyOffice/LibreOffice 即可补齐（见 §6.2）。
2. **RAR/7z 不支持在线目录树**（`java.util.zip` 仅原生支持 ZIP），下载不受影响。
3. 第二阶段"违规文件 ClamAV 杀毒、异常 IP 提醒"预留扩展点未默认内置；登录锁定、限流、操作日志、高危类型拦截已实现。
4. 第三阶段（收藏/最近访问已做简化版、WebDAV、版本管理、离线下载、共享文件夹协作）未包含，见 §6.2 扩展指引。
5. `file_info` 为自增主键 + 分享层用雪花 ID 隔离，短码无法反推任何自增 ID，满足防枚举要求。
6. 口令码当前为**永久有效**（expire_time 字段已预留），如需限时口令码在 `InviteCodeService.generate` 中补传入参即可。
